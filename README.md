# تطبيق عاطف وهبة للهاتف وقاعدة البيانات

هذا المشروع يجهز نسخة Android أصلية باستخدام Capacitor، مع تطبيق ويب متجاوب وواجهة عربية. تُخزَّن الإيصالات في Supabase Postgres، وتتطلب المصادقة. حسابات الموظفين لا ترى إلا الإيصالات التي أنشأها حسابها؛ لا تنشئ حساباً مشتركاً إذا كنت تريد سجلًا موحدًا للفريق، لأن ذلك يحتاج تصميم صلاحيات فريق/فرع مخصصاً.

## إعداد قاعدة البيانات

1. أنشئ مشروعًا في Supabase، واحتفظ بعنوان المشروع ومفتاح `publishable` (أو مفتاح `anon` القديم). لا تضع `service_role` أو أي مفتاح سري في التطبيق.
2. افتح **SQL Editor** في مشروع Supabase، ونفّذ محتوى `supabase/schema.sql` لإنشاء جدول الإيصالات وسياسات RLS.
3. من **Authentication → Users** أنشئ مستخدمي المكتب يدويًا، أو أرسل لهم دعوات. تسجيل المستخدمين العام غير موجود في التطبيق.
4. انسخ `.env.example` إلى `.env` وأدخل بيانات المشروع:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_OR_ANON_KEY
```

المفتاح العام مخصص للاستخدام في تطبيقات العميل؛ أمان البيانات يعتمد على تسجيل الدخول وسياسات RLS في `supabase/schema.sql`. لا ترفع `.env` إلى GitHub.

## تشغيل نسخة الويب محليًا

يتطلب Node.js 20 أو أحدث وnpm:

```bash
npm install
npm run dev
```

## إنشاء تطبيق Android

يتطلب Android Studio وAndroid SDK (و Java/JDK المدعوم من إصدار Android Gradle Plugin الذي يولده Capacitor):

```bash
npm install
npm run build
npm run android:add       # مرة واحدة لإنشاء مشروع Android
npm run android:sync      # بعد كل تعديل على تطبيق الويب
npm run android:open
```

من Android Studio اختبر التطبيق على جهاز أو محاكي، ثم أنشئ APK تجريبيًا أو Android App Bundle للنشر. لا يمكن إنشاء ملف APK/AAB قبل إعداد مفاتيح Supabase وبيئة Android المناسبة.

## iPhone / iOS

يمكن إضافة منصة iOS بأوامر Capacitor على macOS مع Xcode وتثبيت حزمة `@capacitor/ios` أولاً (`npm install @capacitor/ios && npx cap add ios`). ثم شغّل `npm run build && npx cap sync ios` وافتح المشروع في Xcode. بناء وتوقيع نسخة iOS للنشر يحتاجان جهاز Mac وحساب Apple Developer.

## ملاحظات مهمة

- ملفات المشروع الجاهزة لتطبيق الهاتف موجودة في `src/`؛ مجلد Android الأصلي يُولَّد محليًا بواسطة Capacitor بعد تثبيت المتطلبات.
- القاعدة تستقبل الإيصالات فقط. الحسابات والحاسبات تُحسب على الجهاز ولا تُحفظ.
- البيانات تتطلب اتصال إنترنت للوصول إلى Supabase. لا توجد مزامنة دون اتصال؛ لا تعرض نسخة غير محفوظة كأنها سُجلت.
- سياسات الأمان تقصر كل سجل على المستخدم الذي أنشأه. إذا كان المطلوب أن يرى جميع موظفي المكتب سجلاً مشتركاً، فأنشئ تصميمًا للمؤسسة والعضوية والأدوار قبل تغيير السياسات.
- بيانات العملاء شخصية. قلّل البيانات المسجلة، قيّد صلاحيات الحسابات، وأعد النسخ الاحتياطية من أدوات Supabase. لا تخزن كلمات مرور أو بيانات بطاقات الدفع.
- إيصال التسجيل لا يثبت إتمام المعاملة أو استلام الأموال.
