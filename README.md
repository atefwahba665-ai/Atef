# تطبيق عاطف وهبة لإدارة المكتب

تطبيق ويب تقدمي (PWA) عربي متجاوب للهواتف والحواسيب، مستوحى من برنامج Tkinter المرسل. يتضمن حاسبة تقسيط، حساب عهدة وعمولة الموظفين، وإصدار إيصالات وسجلًا محليًا قابلاً للبحث والتصدير.

## تشغيله على الهاتف

1. انشر المستودع باستخدام GitHub Pages: من **Settings → Pages** اختر النشر من فرع `main` ومجلد الجذر.
2. افتح رابط الموقع المنشور في Chrome على Android أو Safari على iPhone.
3. Android: اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية** من قائمة المتصفح. iPhone: اختر **مشاركة → إضافة إلى الشاشة الرئيسية**.
4. بعد أول تحميل، واجهة التطبيق متاحة دون اتصال بالإنترنت. استخدم ميزة التصدير لتنزيل نسخة احتياطية دورية من الإيصالات.

يتطلب التثبيت والعمل دون اتصال استضافة عبر HTTPS (مثل GitHub Pages)، ولا يعمل service worker عند فتح ملف HTML مباشرة. لا تحتاج إلى تثبيت Python أو حزم إضافية.

## البيانات والخصوصية

الإيصالات محفوظة في التخزين المحلي للمتصفح على الجهاز، ولا تُرسل إلى خادم. مسح بيانات المتصفح أو تغيير الجهاز قد يحذفها؛ صدّر ملف JSON للاحتفاظ بنسخة احتياطية. لا تخزّن معلومات حساسة مثل كلمات المرور أو بيانات بطاقات الدفع.

الإيصال يثبت تسجيل المعاملة فقط، وليس إتمامها أو سدادها. نسب الربح والضريبة والعمولة افتراضية وقابلة للتعديل، ويجب التحقق من القيم المطبقة في نشاطك قبل اعتمادها.
